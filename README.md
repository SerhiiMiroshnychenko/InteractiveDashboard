# Інтерактивна інформаційна панель (BI Panel)

Інтелектуальна веб-панель для візуалізації даних із завантажених CSV та Excel файлів. Автоматичне розпізнавання типів колонок, інтерактивні графіки, аналітика та експорт.

## Технології

- **React 19** — UI бібліотека
- **TypeScript** — типізація
- **Vite 6** — збірка
- **Tailwind CSS 4** — стилізація
- **Recharts** — графіки
- **PapaParse** — парсинг CSV
- **SheetJS (xlsx)** — парсинг Excel
- **Lucide React** — іконки
- **Motion** — анімації

## Функціонал

- Завантаження файлів через drag-and-drop або діалог (CSV, XLSX, XLS)
- Евристичне визначення типів колонок: числові, категоріальні, логічні, дати, ID, текст
- KPI-картки з ключовими метриками (сума, середнє, кількість)
- Інтерактивний конструктор графіків:
  - 6 типів: стовпчики, лінії, область, кругова, радар, точковий
  - Групування рядів за категорією
  - Агрегація: сума, середнє, кількість, максимум
  - 5 кольорових палітр
  - Експорт у SVG та PNG
- Таблиця даних з пагінацією, пошуком та сортуванням
- Темна та світла тема (автоматично за системними налаштуваннями)
- Адаптивний дизайн

## Команди

```bash
npm run dev        # Запуск сервера розробки (порт 3000)
npm run build      # Збірка для продакшену
npm run lint       # Перевірка типів TypeScript
```

```
src/

├── main.tsx                   # Точка входу
├── types.ts                   # Типи даних
├── index.css                  # Стилі (Tailwind)
├── components/
│   ├── UploadZone.tsx          # Завантаження файлів
│   ├── KpiSummaryCards.tsx     # KPI-картки
```
